# ABCD benchmark graphs

HOPE and Node2Vec embeddings at several dimensions on ABCD graphs with planted communities. Each embedding gets a CGE divergence score, and KMeans clusters of the embedded nodes are compared with the planted communities using AMI, ARI and a graph-aware agreement score, so method and dimension choices can be compared against a known answer.

Code: the ABCD section of [`../analysis.ipynb`](../analysis.ipynb).
